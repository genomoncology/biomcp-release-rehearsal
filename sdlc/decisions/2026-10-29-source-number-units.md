# Source numbers retain their units

Reviewed publisher fields on 2026-10-29 for 0451. A small shared `WithUnit` value pairs the existing checked numeric value with the exact publisher unit or code. An unstated unit stays absent. A malformed stated unit rejects that quantity and reports the source field. Values are never converted.

- HPA [programmatic downloads](https://www.proteinatlas.org/about/download) return gene JSON with `RNA tissue specific nTPM` and `RNA cancer specific pTPM`. The [publisher tissue data description](https://www.proteinatlas.org/humanproteome/tissue/data) names normalized expression nTPM and protein-transcripts per million pTPM. The adapter attaches those explicit field units to each abundance.
- SEER [Explorer](https://seer.cancer.gov/statistics-network/explorer/application.html) defines incidence as new cases per 100,000 people and relative survival as a percentage. The checked `rate` estimate, standard error and confidence bounds retain `per 100,000 people`; `rel_rate` and `modeled_rel_rate` retain `%`. Native counts remain counts without an invented unit or denominator.
- NCI's [published trial field mapping](https://github.com/NCIP/clinical-trials-search/blob/master/search/index/indexer/trial/mapping.json) declares the structured age text, number, unit and in-years fields. Its [publisher supplement](https://github.com/NCIP/clinical-trials-search/blob/master/import/transform/stream/supplement.js), `_createAgeInYears`, assigns `min_age_in_years` and `max_age_in_years`. BioMCP retains those already supplied values with `Years`; it does not execute the publisher conversion. The existing unchanged public-tier recording `tests/replies/trial/nci/get/nci/0ff7f0680eaac3c3449fdeaf1991cb1d45fc79a573dd082b98072969924be141.json` returns min age number 18, unit `Years`, raw text `18 Years`, and max age number 999, unit `Years`, raw text `999 Years`. Both numeric sentinels and raw text stay unchanged.
- openFDA's [drug event field reference](https://open.fda.gov/fields/drugevent.yaml) declares `patientonsetage` as a string containing a float and `patientonsetageunit` as its interval unit. Codes are exactly `800` Decade, `801` Year, `802` Month, `803` Week, `804` Day and `805` Hour. The numeric age retains that strict code without conversion or clinical interpretation.

Regular response schemas and their consuming majors change together. The final release candidate owns the release baseline.
