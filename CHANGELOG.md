# Changelog

## 1.0.0

BioMCP 1.0 introduces JSON response envelopes, one CLI grammar shared with MCP, explicit source records and stored continuations. It replaces 0.9 command, configuration and output contracts. Read the [release notes](release/notes.md) and [upgrade guide](sdlc/planning/upgrade.md) before upgrading. FHIR patient reading is planned for 1.1.
